# Feature reference

This is the broad inventory. Names and controls may move while the client is in active development.

## Dungeons

Orion contains the dungeon map, score HUD, secret waypoints, route rendering and chest-profit display. Puzzle support covers terminals, Blaze, Boulder, Ice Fill, Water Board, Silverfish, Tic-Tac-Toe, Creeper Beams and trivia. Combat overlays include starred mobs, minibosses and Livid identification.

Pegasus adds party shortcuts, reparty, ready checks and carry-mode tools.

## Mining

Aquila tracks powder, commissions and forge slots. It also contains helpers for cold, Pickonimbus durability, Fetchur, Puzzler, the Wishing Compass and Crystal Nucleus progression.

## Farming

Hercules covers Garden contests, visitors, pests, crop milestones, composter state, movement guidance and plot information.

## Fishing

Hydra tracks catches, sea creatures and trophy fish. Optional displays cover bait, barn fishing, Golden Fish timing, hotspots and Thunder-related drops.

## Economy and inventory

Lyra adds purse tracking, Bazaar values, auction information, storage previews, inventory search and item-value helpers.

## Events and combat

Cygnus handles the calendar, mayor information, event alerts and Diana waypoints. Draco covers Crimson Isle state, Kuudra phases, reputation and island-specific activities. Perseus contains Slayer timers, progress and drop tracking.

## Client tools

Apollo owns the shared HUD layer. Cassiopeia handles chat cleanup, timestamps, mention alerts and command shortcuts. Phoenix contains visual and input quality-of-life options. Auriga groups experiment helpers and smaller utilities. Andromeda handles Rift state and waypoints.

Every module has a master switch. Individual features remain configurable from the same screen.
