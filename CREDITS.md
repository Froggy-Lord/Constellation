# Credits

Constellation includes adapted code and bundled data from open-source SkyBlock projects. The project is distributed under GPL-3.0-only so those sources and later modifications remain available under compatible terms.

## Implementations and technical references

| Project | License | Areas used or studied |
| --- | --- | --- |
| [Skyblocker](https://github.com/SkyblockerMod/Skyblocker) | LGPL-3.0 | Room transforms, dungeon state, rendering and several helpers |
| [Odin](https://github.com/odtheking/Odin) | BSD-3-Clause | Puzzle behaviour, Etherwarp guidance and Master Mode helpers |
| [Devonian](https://github.com/Synnerz/devonian) | GPL-3.0 | Modern Fabric dungeon behaviour and rendering reference |
| [NoFrills](https://github.com/WhatYouThing/NoFrills) | GPL-3.0 | Dungeon highlights and combat helpers |
| [Secret Routes](https://github.com/yourboykyle/SecretRoutes) | GPL-3.0 | Route format, bundled routes and route playback |
| [Dungeon Rooms Mod](https://github.com/Quantizr/DungeonRoomsMod) | GPL-3.0 | Room fingerprints and secret-location data |

SkyHanni, Skytils, Dungeons Guide and SkyOcean were also studied when checking behaviour across Minecraft versions. Their work is not presented here as original to Constellation.

## Bundled data

- `secretlocations.json` and the Catacombs room data retain the Dungeon Rooms Mod copyright and GPL notice.
- `routes.json` and `pearlroutes.json` retain their Secret Routes origin and copyright fields.
- Attribution files stored beside imported datasets remain part of release artifacts.

Project names belong to their respective maintainers. This file describes provenance; it does not imply endorsement.
